🍏 Script Launchd macOS

Le script ./scripts/setup_daily_cron.sh prépare le descripteur com.claude.changelog.daily.plist avec le binaire absolu Python et RunAtLoad=false.

./scripts/setup_daily_cron.sh

Généré localement dans le dossier scripts/. Non installé par défaut (pour charger dans ~/Library/LaunchAgents : ./scripts/setup_daily_cron.sh --install).

🐧 Crontab Linux / Mac

Si vous préférez une commande cron manuelle dans votre propre ordonnanceur :

0 4 * * * cd /chemin/vers/Claude-ChangeLogs && python3 scripts/update_changelog.py >> logs/cron.log 2>&1

Exécution locale sans écriture hors du dossier de travail.
